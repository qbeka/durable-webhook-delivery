The problem

A receiver records an expense, then the response is lost. The sender cannot tell this from a request that never arrived, so it has to try again. Retry blindly and the expense is recorded twice. Do not retry and it can be lost.

No sender can solve this alone. So this project defines what a receiver must do, builds both sides, and then tries to break them on purpose.
